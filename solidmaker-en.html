SolidMaker

Design · Simulation · Manufacturing

Open engineering software, developed in Mexico, that takes a part from the first sketch to the machine that makes it without switching programs.

The same model is drawn in PolarCAD, assembled, tested in Laboratory, analysed in Analizer, sliced in PolarSlicer and manufactured from Machin. No intermediate exports, no files lost along the way.

00 / Why it existsMotivation

Engineering tools should not be a privilege.

In Mexico, an engineering student learns to design with educational licences that expire on graduation day. A small workshop can rarely pay for CAD, CAM and simulation separately.

SolidMaker was born to close that gap. It is a single open program for students, makers and workshops who want to build what they design. Its code can be read, studied and improved, and its formats are open so your projects stay yours.

We use it first. Every Stonward machine is designed, tested and controlled with SolidMaker, so every feature exists because we needed it in the workshop.

Vision

In every engineering classroom in the country.

We want universities in Mexico and Latin America to teach with SolidMaker, so a student designs, tests and builds with the same tool they will later work or start a business with. If your institution wants to join the trials, write to us.

01 / ModulesOne model, five stages
Module 01

PolarCAD

Parametric design. Sketches with dimensions and geometric constraints, exact solids by extrusion, revolution and sweep, cuts, fillets, patterns, sheet metal and machining features such as tapped holes. Assemblies use real mechanical joints: hinges, sliders, threads, gears and GT2 belts, which you can test with motors and servos.

  • Imports and exports STEP, IGES and STL
  • Library of fasteners, profiles, bearings, pulleys and NEMA motors
  • Interference detection with a clearance map
See in the manual
Module 02

Machin

The digital twin of every machine. It loads the full model of the printer, robot or CNC, simulates G-code with its real kinematics (Cartesian, polar, delta, six-axis arm, five-axis or lathe) and connects to the controller over serial to run it.

  • Installable machine packages (.zip)
  • Toolpath pre-computation with reach indicator
  • Joint-space G-code with timing identical to the simulation
See in the manual
Module 03

PolarSlicer

Generates manufacturing toolpaths. It slices in planes, diagonally or in elliptical layers, and builds tree or layered supports that save material. For milling and turning it produces roughing passes. Output is G-code for Cartesian machines and lathes, and oriented S-code for polar, delta, arm and five-axis kinematics.

  • Supports and G-code computed in C++
  • Layer-by-layer preview, including CNC roughing
  • Machine selector linked to Machin
See in the manual
Module 04

Laboratory

The virtual test bench. It imports the assembly and its kinematics, solves closed-loop mechanisms, simulates physics and wires the electronics: power supplies, a ladder-logic PLC, sensors and actuators, with the circuit solved in ngspice to show real voltages and currents.

  • Ladder editor with live execution
  • Automatically routed wiring with terminal names
  • Alerts for shorts, overloads and unpowered loads
See in the manual
Module 05

Analizer

Engineering analysis. It meshes the part, computes stress and deformation with finite elements, and simulates wind and flow around the design, so you can validate an idea before spending material.

  • Meshing with diagnostics
  • Structural FEA
  • Wind and flow CFD with field results
See in the manual
02 / IncludedWhat comes with every install

Standard library

1,535 components in 81 families: ISO fasteners, aluminium profiles, bearings, linear rails, lead screws, GT2 pulleys, gears and NEMA 17 and 23 motors. They are inserted already sized and with their material.

CadQuery kernel

Solids are exact (B-rep on OpenCascade), not meshes. That is why a hole stays round, a STEP file comes out clean and dimensions match the real part.

Assistant

A built-in console takes written commands and runs them on the model, so repetitive work takes a single line.

Projects

A manager organises parts, assemblies and machines in folders. Autosave lets you recover unsaved work after an unexpected shutdown.

Native computing

Heavy work such as supports, G-code, kinematics and mechanisms runs in compiled C++ modules, not in the browser.

Made to fit

Seven languages and nine colour themes, plus one of your own. The 3D viewer and every module follow the chosen theme.

04 / InstallationStep by step
Install on Windows
  1. Download SolidMaker-Setup.exe from this page.
  2. Open it. If Windows shows “Windows protected your PC”, choose More info and then Run anyway.
  3. Accept the suggested folder, or pick another, and press Install. The C++ computing modules and the library are included.
  4. Open SolidMaker from the Start menu. The first time it prepares the component library, which takes a few minutes and happens only once.
  5. Choose language and theme in the settings. To start drawing, follow the PolarCAD tour.
Install on Linux
  1. Download the Linux package.
  2. Extract it into your programs folder.
  3. Run the solidmaker launcher. The first time it prepares the component library.
  4. To connect a machine over USB, add your user to the dialout group and log in again.
Install on Android
  1. Download the .apk file from this page on your phone or tablet.
  2. Allow installation from your browser when Android asks.
  3. Open SolidMaker and load your projects from the device storage.
Install a Stonward machine
  1. Open the machine sheet in Machines and download its .zip package.
  2. In SolidMaker open Machin and then Machine → Acquire new machine.
  3. Choose the .zip and restart SolidMaker. The machine appears in the menu with its model, kinematics and driver.

Final instructions for each platform are published with every release.
